{%- comment -%} Local CV layout, modelled on Kousha's 2023 CV design. This site used to pull sproogen/resume-theme over `remote_theme`; nothing is inherited any more, so everything the page needs lives in this repo (_layouts, _includes, _sass). Structure, and why: * The sheet is a . Chromium repeats a at the top of every printed page and reserves its height in the flow, so the charcoal band reaches pages 2, 3, 4… from a single element. `position: fixed` cannot do this: Chromium anchors fixed boxes to the page *content* box, so the band cannot be pushed up into the paper margin where the reference puts it. (Verified against Chromium's own PDF output, both ways.) * The sidebar is a right float rather than a grid or flex column. In the reference design the two-column split only lasts as long as the sidebar has content; once it runs out the main column widens to the full page. A float reproduces that for free, in print as well as on screen — but it only works if the float precedes the content that wraps around it, hence the sidebar appearing first in source order. * There is no dark mode. The old theme's dark mode carried no print rules, so an exported CV came out as pale grey text on white; this design is a paper design and is light in both media. `darkmode:` in _config.yml is inert. _sass/_cv.scss still resets `.dark` under @media print in case anything else ever sets that class, and export-button.html still strips it. {%- endcomment -%} {%- include head.html -%}
